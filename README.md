# Joseph Karikari

I'm a software engineer and a teacher by training (BSc Information Technology Education, University of Education, Winneba). 
That combination shapes how I work: I build the system, then train the people who have to use it.

I lead mobile and backend development for public-sector projects in Ghana. 
I also support computing education through junior high school ICT clubs and teacher training with the Ghana Education Service.

I am interested in graduate research in computer science, software engineering and applied AI.

## What I work on
- **Offline-first field data collection: Ghana Child Labour Monitoring System (GCLMS), currently in pilot testing — Flutter, SQLite, synchronization queues.
- **National education data systems:**  EMIS Census web platform and mobile application — PHP, MySQL, Flutter.
- **Real-time location platform:** Orbit ride-hailing applications — Firebase, WebSockets, Google Maps.
- **Applied AI:** Ghana Card information extraction using Google Document AI, integrated with a PHP REST API.

## Public work
- [flutter_geofire with rotation](https://github.com/karikarijoseph8/advance-geofire): Fork of [flutter_geofire](https://github.com/mrdishant/flutter_geofire) by mrdishant (MIT). I added Android driver marker rotation and location accuracy metadata, used in the Orbit Driver app.
  
Most of my professional work is for clients and is private.
